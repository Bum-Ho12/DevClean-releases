DevClean

Free disk space taken by developer caches and build files on your Mac. It shows what each item uses and deletes only what you tick.

Needs macOS 13 or later. Works on Apple silicon and Intel.

Install

Paste this into Terminal. It downloads the latest release, checks it, and installs DevClean to Applications without the macOS "downloaded from the internet" block.

curl -fsSL https://raw.githubusercontent.com/Bum-Ho12/DevClean-releases/main/scripts/get.sh | bash

Prefer to do it by hand? Download the zip, unzip it and run bash install.sh from the folder. Details are in the README.

What it cleans

XcodeDerivedData, iPhone device support files, simulator caches and logs. Archives are listed, never deleted.
Android & GradleUnused Gradle versions, daemon logs, the dependency cache, downloaded JDKs, Kotlin/Native and emulator snapshots.
Your projectsBuild folders and dependency folders (node_modules, Pods, Cargo target) in your projects, optionally only for projects idle for 30+ days.
Package managersCocoaPods, Homebrew, npm, Yarn, pnpm, Maven, Cargo and pip caches, JetBrains and Android Studio caches, plus the Trash.

One Gradle for all your projects

Every project shares one Gradle cache, but each Gradle version it pins is a separate download. When your projects use different versions, Align Gradle Versions… moves the ones you tick to a single version so the rest can be cleaned.

  • It checks the Android Gradle Plugin and skips projects that need a newer Gradle. Major version jumps are shown in yellow and start unticked.
  • Projects with uncommitted changes to gradle-wrapper.properties, and projects you pin, are left alone.
  • Originals are backed up to ~/Library/Application Support/DevClean/Backups before anything is edited.

Safe by design

  • You review the exact folders before anything is deleted.
  • It never touches source code, SDKs or settings. Everything it removes is rebuilt when a tool needs it. The only project file it edits is the Gradle wrapper file, and only when you use Align Gradle Versions.
  • No accounts, no analytics. The only network request is the update check you start yourself.
